# 🚀 Featured Project

## 🤖 RAG-Based AI Chatbot

An intelligent chatbot designed to answer questions using information retrieved from websites and additional documents.

### ⚡ Main Features

- 🌐 Website content ingestion
- 🕷️ Web scraping
- 📄 PDF document processing
- 🧹 Content cleaning
- ✂️ Text chunking
- 🧠 Sentence Transformer embeddings
- 🗄️ Qdrant vector database
- 🔎 Semantic vector search
- 📚 Relevant-context retrieval
- 🤖 LLM integration
- 💬 Context-aware answers
- 🚫 Reduced unsupported responses
- 🔄 Website knowledge synchronization
- 🎨 Website-integrated chatbot interface

### 🏗️ RAG Flow

```text
WEBSITE / PDF
      │
      ▼
┌──────────────┐
│ Data Loader  │
└──────┬───────┘
       │
       ▼
┌──────────────┐
│ Data Cleaner │
└──────┬───────┘
       │
       ▼
┌──────────────┐
│ Text Chunker │
└──────┬───────┘
       │
       ▼
┌───────────────────────┐
│ Sentence Transformers │
└───────────┬───────────┘
            │
            ▼
      ┌────────────┐
      │ Embeddings │
      └─────┬──────┘
            │
            ▼
      ┌────────────┐
```
