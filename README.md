## 🌟 Flagship Project Showcase

### 🤖 Production-Grade RAG AI Chatbot System

A high-performance Retrieval-Augmented Generation agent capable of dynamically scraping web domains, parsing unstructured PDF documents, building dense vector embeddings, and serving real-time semantic queries via Qdrant & LLMs.

#### 🏗️ Architecture Pipeline Visualizer

```text
┌──────────────────────────────┐
│  Data Sources (Web / PDF)    │
└──────────────┬───────────────┘
               │
               ▼
┌──────────────────────────────┐
│   Crawler & Sanitizer        │
└──────────────┬───────────────┘
               │
               ▼
┌──────────────────────────────┐
│ Text Chunking (Recursive)    │
└──────────────┬───────────────┘
               │
               ▼
┌──────────────────────────────┐
│ Sentence Transformers Model  │
└──────────────┬───────────────┘
               │
               ▼
┌──────────────────────────────┐
│ Qdrant Vector Collection     │
└──────────────┬───────────────┘
               │  ◄─────── USER QUERY (Semantic Search)
               ▼
┌──────────────────────────────┐
│ Context Injection Engine     │
└──────────────┬───────────────┘
               │
               ▼
┌──────────────────────────────┐
│ LLM Synthesis & Response     │
└──────────────────────────────┘
```

#### ✨ Key Technical Accomplishments
- ⚡ **Web Crawling & PDF Parser**: Seamlessly ingests external articles and structured PDFs.
- ✂️ **Smart Text Chunking**: Implements overlapping character chunking to preserve contextual boundaries.
- 🗄️ **High-Velocity Vector Store**: Leverages Qdrant DB for cosine similarity search.
- 🎯 **Hallucination Prevention**: Restricts responses strictly to verified context payloads.
